# Claims and evidence

| Claim | Argument | Evidence and dependencies |
|---|---|---|
| Every forward regular-circle-preserving homeomorphism is differentiable almost everywhere | Monotonicity on embedded graph subarcs, Fubini and Gehring–Lehto | Manuscript §2. The result for general open maps is classical. |
| The constructed planar map is bilipschitz with a Cantor set as its exact singular set | Disjoint radial patches, uniform derivative bounds and alternating vertical quotients | Manuscript §§3 and 5. The finite replay checks only disk geometry, scaling and quotient bounds. |
| Both the map and its inverse preserve every embedded regular C¹ circle as a subset | Direction estimates for every pair in a deep core, graph monotonicity and continuity of image slopes | Manuscript §4. This is an analytic argument. |
| The planar example localizes to each smooth surface | The modification is the identity near the outer chart boundary | Manuscript §5. Bilipschitz bounds refer to local coordinates. |
